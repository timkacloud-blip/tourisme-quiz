# Запуск за 4 шага

## 1. Таблица и скрипт (заявки + менеджер + Meta)
1. Создайте Google Таблицу «TOURisME заявки».
2. Расширения → Apps Script. Вставьте всё из `backend/Code.gs`, сохраните.
3. Проект → Настройки → Свойства скрипта, добавьте:
   - `MANAGER_KEY` — пароль менеджера
   - `PIXEL_ID` — ID пикселя
   - `CAPI_TOKEN` — токен Conversions API (Events Manager → Настройки → Генерация токена)
   - `TEST_CODE` — код тестовых событий, пока проверяете (потом удалить)
   - `SITE_URL` — адрес сайта
4. Развернуть → Новое развёртывание → Веб-приложение. Запуск от: «Меня», доступ: «Все». Разрешите доступ. Скопируйте адрес `.../exec`.

## 2. Адрес в страницах
- `index.html`, блок `CFG`: `PIXEL_ID` и `ENDPOINT` (адрес из шага 1).
- `manager.html`: строка `const ENDPOINT` (тот же адрес).

## 3. GitHub Pages
Залейте папку в публичный репозиторий, Settings → Pages → ветка main. Сайт: `https://ВАШ-ЛОГИН.github.io/РЕПО/`, менеджер: `.../manager.html`.
Пароль менеджера хранится только в Apps Script, в репозитории его нет.

## 4. Реклама
Ссылка в объявлении: `https://.../?utm_source=fb&utm_campaign={{campaign.name}}&utm_content={{ad.name}}`. Язык можно задать `&lang=uz` или `&lang=ru`, иначе берётся язык телефона.

## Как работает у менеджера
- В конце дня заходит на `manager.html`, видит заявки за день.
- Код заявки (например `W5GFR`) стоит в сообщении клиента в Telegram, по нему находится заявка.
- Кнопки: **Треш**, **Квал**, **Продажа** (с суммой). Повторное нажатие сбрасывает.
- «Квал» отправляет в Meta событие `QualifiedLead`, «Продажа» — `Purchase` с суммой. Лучше отмечать в тот же день: Meta принимает события не старше 7 дней.
